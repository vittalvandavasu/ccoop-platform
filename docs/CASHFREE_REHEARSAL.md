## Evidence retention gap and source contract

The handler uses original raw bytes for authentication but persists normalized observations, not the raw webhook. There is no approved durable raw-payload retention facility or schedule in this repository. Before rehearsal, security/privacy owner must approve restricted capture location, encryption/access, retention and deletion. Do not log raw payloads, signatures, auth headers, PII or session tokens into normal app/CI output. Keep any approved original bytes protected for signature analysis and derive a redacted summary for sharing; redacting original bytes would invalidate byte-for-byte signature reproduction. Until this is configured, mark raw-evidence retention NOT VERIFIED.
